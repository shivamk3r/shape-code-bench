01 / THE IDEA

Simple shapes.
A demanding visual test.

Recognizing a circle is a start. Recovering its position, radius, stroke, and relationship to other shapes asks much more.

01

Perception meets code

Models infer shape types and integer parameters from pixels, then express them in a small, shared drawing language.

02

Compare the renders

A restricted parser and deterministic renderer turn each prediction into an image. Visual equivalence matters more than code-string equality.

03

Refresh the evaluation

Fresh seeds create new held-out instances without manual annotation. Renewability reduces memorization of exact examples.

Fresh instances reduce exact-example contamination. Models can still learn the generator distribution; held-out seeds and careful split separation remain essential.

02 / THE PROTOCOL

Image in.
Executable understanding out.

The same compact language spans every difficulty tier. Complexity comes from the scene.

  1. 01 →

    Generate a scene

    A seeded generator samples circles and squares, with filled or outlined variants, on a black-on-white canvas.

    IMAGE + CANONICAL PROGRAM
  2. 02 →

    Recover the program

    The model receives the image and a fixed zero-shot DSL description, then emits drawing calls with integer parameters.

    MULTIMODAL MODEL → DSL
  3. 03 ↳

    Render and measure

    The evaluator validates approved calls, renders the prediction, and measures exact match, pixel accuracy, and foreground IoU.

    RENDER → COMPARE → SCORE

What do the scores measure? +

Exact match requires every rendered pixel to match. Different programs can earn the same score if their renders are identical.

Pixel accuracy is the fraction of all matching pixels. A large white background can make this score look high despite shape errors.

Foreground IoU measures the intersection over union of black pixels. It isolates how well the actual shape structure is recovered.

Parse success tracks valid DSL output. It measures structural validity; a valid program may still reconstruct the wrong scene.

Source: paper/tables/main_results.csv · Paper and experimental protocol. Deterministic images and scoring; model inference can vary between runs.

05 / BUILD ON IT

Reproduce it.
Refresh it. Extend it.

Start locally with the benchmark core. Generate a separate development split, or load the frozen dataset for held-out reporting.

01 / RUN LOCALLY

Python 3.12 and uv

git clone https://github.com/shivamk3r/shape-code-bench.git
cd shape-code-bench
uv sync --dev
uv run shape-code-bench generate \
  --split dev --difficulty easy \
  --count 6 --seed 101
